# 果沐兄弟 · 火柴人：突围行动

原生 Canvas 横版动作游戏。项目已加入九关扩展路线、分层场景、统一敌人美术和特工外观成长。

## 本地试玩

```sh
npm install
npm start
```

打开 http://127.0.0.1:4173。Boss 动作可在 http://127.0.0.1:4173/boss-motion-preview.html 单独查看。也可以使用任意静态 HTTP 服务器托管项目根目录。

## 本次更新

- 九关均保留原地图，追加六段不同敌人组合与地形节奏的路线和独立 Boss 场地。长度约为最初版本的 2.7–4.1 倍，每关共八个区域、六个补给点，新增分区提示、补给地标、推进进度和最近敌人方向。
- 新增突击枪兵、散弹兵、战地医师、棱镜哨兵四种行为；所有 17 种小兵使用统一风格的立体装甲素材。冲锋锁定方向、散弹扇形前摇、治疗范围和三连发蓄力有对应视觉反馈。
- 九位 Boss 各有 16 格独立动作图（共 144 个姿态）：奔跑、蹲伏蓄力、举武器、挥击、腾空、下降、落地、施法与受击。攻击按蓄力、出手、收招推进；冲锋锁定朝向，跳砸实际走抛物线并在落地后放出冲击波，收招提供反击窗口。保留阶段切换、弱点和地面预警。清场后到达决战区才开始首领战。
- 九套主题全景叠加远景、中景建筑或树木、雾层、光束、近景剪影；平台有立体顶面、侧面、接触阴影和按主题变化的地面材质。
- 主角按每位特工的经验等级进化：Lv.1 侦察新兵、Lv.3 疾风游侠、Lv.6 苍蓝先锋、Lv.10 星辉统领、Lv.15 天穹守卫、Lv.20 破晓传奇。保留白色圆头和细长四肢，逐步增加护腕、肩甲、头饰、光翼与光环；围巾随等级加长。外观不额外改变战斗数值。
- 成长中心展示六阶段概念形象、当前实际战斗外观和下一个解锁等级；跨等级结算会展示外观解锁。旧存档和特工独立存档继续可用。
- 远处敌人接近玩家后才开始行动，飞行敌人不再受重力或平台干扰；时间奖励按扩展长度调整。

## 文件

- `campaign.js`：追加路线、敌群编排、补给与决战区。
- `boss-motion.js`：Boss 动作时间轴、锁定目标、跃击弹道、收招与帧选择。
- `boss-motion-preview.html`：可选择九个 Boss 和动作、调速或暂停的独立演示。
- `enemy-types.js`：四种新增敌人的状态机及预警。
- `art.js`：图集、视差、阴影与立体平台材质；素材失败时保留原矢量后备画面。
- `hero-appearance.js`：外观等级和附着在原 IK 动画上的装甲。
- `assets/generated/`：已接入项目的生图素材。
- [素材生成提示词](docs/ASSET-PROMPTS.md)：内置 image_gen 的完整提示词及用途；九套动作图的原始输出、项目路径和逐张完整提示词见 `docs/BOSS-MOTION-ASSETS.json`。

## 验证

```sh
npm test
npm run test:browser
```

浏览器测试使用 Puppeteer，可通过 `CHROME_PATH` 指定本机 Chrome。它会启动独立临时端口，在隔离的浏览器会话中验证九关扩展段的实际移动、九位 Boss 出场、远处敌人激活、成长外观、移动端和资源缺失后备渲染。截图和结果保存在被 Git 忽略的 `test-results/`。测试中的路线检查不等同于人工完成全部战斗；实战难度和节奏可继续根据试玩反馈调整。
