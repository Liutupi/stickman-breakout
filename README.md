# 果沐兄弟 · 火柴人：突围行动

原生 Canvas 横版动作游戏。项目已加入十关长路线、分层场景、统一敌人美术和特工外观成长。

## 本地试玩

```sh
npm install
npm start
```

打开 http://127.0.0.1:4173。Boss 动作可在 http://127.0.0.1:4173/boss-motion-preview.html 单独查看。也可以使用任意静态 HTTP 服务器托管项目根目录。

## 文件

- `campaign.js`：追加路线、敌群编排、补给与决战区。
- `boss-motion.js`：Boss 动作时间轴、锁定目标、跃击弹道、收招与帧选择。
- `boss-motion-preview.html`：可选择十个 Boss 和动作、调速或暂停的独立演示。
- `enemy-types.js`：扩展兵种的状态机及预警。
- `aerial-art.js`：八类空中机体的四姿态图集、飞行倾斜、推进特效与攻击预警。
- `art.js`：图集、视差、阴影与立体平台材质；素材失败时保留原矢量后备画面。
- `hero-appearance.js`：外观等级和附着在原 IK 动画上的装甲。
- `assets/generated/`：已接入项目的生图素材。
- `assets/audio/`：第六至第十关配乐、连杀与第六关结算录音；对应原文件与曲目见 [音频素材记录](docs/AUDIO-ASSETS.json)。`scripts/prepare-audio.py` 可从普通 MP3 重新导入并统一响度。
- [素材生成提示词](docs/ASSET-PROMPTS.md)：内置 image_gen 的完整提示词及用途；九套动作图的原始输出、项目路径和逐张完整提示词见 `docs/BOSS-MOTION-ASSETS.json`。
- [空中机群素材记录](docs/AERIAL-ART-ASSETS.json)：八套独立设计的完整生图提示词、原始 PNG 输出与运行时 WebP 路径。
- [第十关素材记录](docs/LEVEL10-ASSETS.json)：内置 image_gen 生成的星环全景与星环主宰 16 姿态图，包含完整提示词、原始输出、PNG 后备与 WebP 路径。

## 验证

```sh
npm test
npm run test:browser
npm run test:audio
npm run test:combat-audio
npm run test:aerial
npm run test:coop
```

浏览器测试使用 Puppeteer，可通过 `CHROME_PATH` 指定本机 Chrome。它会启动独立临时端口，在隔离的浏览器会话中验证前九关扩展段与第十关完整路线的实际移动、十位 Boss 出场、远处敌人激活、成长外观、移动端和资源缺失后备渲染；也会验证第九关结算、解锁、强化、进入第十关和最终结局衔接。截图和结果保存在被 Git 忽略的 `test-results/`。测试中的路线检查不等同于人工完成全部战斗；实战难度和节奏可继续根据试玩反馈调整。

`test:aerial` 额外验证八类设备的四姿态、原碰撞尺寸、俯冲锁定红线、炮艇投弹、三类新增设备的实战渲染、结局巡礼及素材缺失后备。

`test:coop` 使用浏览器真实鼠标事件及模拟手柄，检查双人键鼠瞄准与子弹方向、触屏电脑、输入源切换和两名玩家的输入隔离。

`test:audio` 验证新增 MP3 的实际浏览器解码、十关换曲、真实击杀的连杀字幕与播报、第六关首领结算，以及静音换关、后台暂停、音量更新、语音失败和旧回调取消。自动化验证不替代实际扬声器上的听感检查。

`test:combat-audio` 验证六条新增录音的解码，以及高阶连杀、狂暴开启、Boss 阶段切换和大招前摇的真实触发、预警优先级、冷却和底部更新提示隐藏。
